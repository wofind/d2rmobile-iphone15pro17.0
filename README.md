# 暗黑破坏神 II：狱火重生 运行客户端 (D2R Mobile)

这是一个将《暗黑破坏神 II：狱火重生》(Diablo II: Resurrected) 适配至手机/移动端体验的开源工具包，支持虚拟摇杆映射、手柄直连以及低延迟串流/本地渲染。

## 核心特性

- **双模控制支持**：深度适配触屏虚拟按键轮盘、快捷法术栏，并原生兼容主流蓝牙/Type-C 手柄（Xbox、DualSense、八位堂、小鸡等）。
- **优化按键映射**：针对暗黑2重制版主机模式的摇杆逻辑与交互按键进行重映射，操作流畅不遮挡视野。
- **自定义布局**：支持调整屏幕 UI 透明度、按钮大小与振动反馈。
- **低延迟通信**：优化码率控制与渲染帧同步，保障刷怪与地牢探索的跟手性。

## 前置准备

在开始配置前，你需要自行准备以下内容：

1. **游戏数据文件**：
   - 提取自正版 Switch / PC 端的完整游戏数据及对应补丁（请放置于指定目录，详见下方说明）。
2. **硬件环境**：
   - **Android**：Android 10.0 及以上系统，推荐骁龙 870 / 天玑 8100 或更高性能芯片。
   - **iOS**：iOS 15.0 及以上（需自签或通过 TestFlight / AltStore 侧载安装）。
3. **网络要求**（若采用串流模式）：
   - 建议在 5GHz Wi-Fi 或局域网内运行，保障帧率与抗丢包表现。

## 安装与快速启动

### 1. 下载应用
前往本仓库的 [Releases 页面](../../releases) 下载最新版本的安装包：
- Android 用户：下载 `.apk` 文件并安装。
- iOS 用户：下载 `.ipa` 文件，使用 AltStore / Sideloadly 进行签名安装。

### 2. 放置游戏数据
首次启动应用后，App 会在本地生成存储目录，请将自行提取的游戏文件导入对应路径：

- **Android 路径**：
  ```text
  /sdcard/Android/data/<你的包名>/files/games/d2r/

```

*(也可直接在 App 设置中点击“选择游戏资源路径”手动定位)*

* **iOS 路径**：
通过系统“文件”App 或电脑端管理工具，将游戏数据拷贝至应用的 `Documents/d2r/` 目录下。

### 3. 控制与画质设置

1. 打开客户端，在首页确认游戏资源状态检测通过。
2. 进入 **控制设置 (Controls)**：
* 使用手柄：蓝牙/有线连接手柄后，按键将自动映射为官方手柄键位。
* 使用触屏：可开启“虚拟屏幕按键”，并在界面编辑模式中自由拖动、缩放按键位置。


3. 进入 **画质设置 (Performance)**：
* 根据设备性能选择 720p 30fps（长续航）或 1080p 60fps（高画质）。

## 常见问题 (FAQ)

**Q: 启动提示“找不到游戏核心文件/Data missing”怎么办？**
A: 本项目不附带游戏资产。请检查你的游戏提取文件格式是否完整，以及文件夹路径是否与应用要求的结构一致。

**Q: 触屏虚拟按键可以隐藏吗？**
A: 可以。连接外接手柄后，可在应用内勾选“连接手柄时自动隐藏触屏 UI”。

**Q: 游戏运行时发热/掉帧严重如何改善？**
A:

* 降低渲染分辨率（建议先以 720p 运行）。
* 关闭高抗锯齿与额外后处理特效。
* 如果是串流架构，请优先确认路由器处于 5GHz 频段且未开启省电模式。
